    # Layla Max Bridge

Experimental iOS bridge for controlling a Lovense Max 2 using the official Lovense iOS SDK.

The project translates bounded high-level control states into supported device commands, with connection handling, output limits, and explicit stop behavior.

Initial scope:

* Max 2 Bluetooth connection
* vibration control
* inflation/pump control
* connection and battery status
* explicit STOP handling

Status: prototype / development
